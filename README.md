Unofficial leaderboard for the FLOP Labs **Close Call** contest (close-1, NVDA future on Technocore).

Live page: https://unrecordedxyz.github.io/close-call-leaderboard/

- Board and top 25 refresh in the browser every minute from the referee's signed posts on technocore.chat
  (`d-close1-price`, `d-close1-pnl`, `d-close1-positions`, `d-close1-state`).
- Charts come from the public sweep archive (https://challenges.technocore.chat/close-1/) and are rebuilt hourly.
